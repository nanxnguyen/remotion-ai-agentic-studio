# 02 · Documentation: every phase leaves its documents

Each video's evidence lives in `docs/<vid>/`. Another agent must be able to continue the video cold from these files alone, and every reviewer scores from them. **A phase without its documents is not done**, in every mode: light mode, user-supplied script or voice, a rushed fix, a cold handoff.

Legend: **E** = `set ... done` refuses without it · **A** = `pipeline.py audit` fails without it · **R** = the gate's reviewer must return `revise` (Cao ticket "evidence missing: <path>") without it.

## D2 · Writing rules

- Write the document **in the same step** as the work it records, not at the end of the video. Update it when the work changes; a stale document is a defect.
- Every number carries its source (command, tool output, timestamp). Never write a duration, score, loudness or check result you did not measure. Write "not measured" instead.
- Each review round appends to the gate's report; earlier rounds are never deleted.
- Use the exact file names above. A differently named file is not found by the checks; rename it instead of adding a second copy.
- Documents are English or Vietnamese as the skill specifies; spoken lines and captions are copied verbatim from `voice.json` / `content-pack.md`.
- Do not store secrets, personal voice previews or unlicensed media in `docs/`.
