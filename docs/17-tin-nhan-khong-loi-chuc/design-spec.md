# Design specification

## frontend-design pass
**Design thesis:** “An is everyone's notification, yet the candle is hers alone.” Restrained cinema rather than generic social content cards.

| Token | Value | Usage |
| --- | --- | --- |
| midnight | `#08090B` | full frame |
| soft-white | `#F5F5F4` | stick figure and headline |
| ash | `#85878A` | supporting text |
| amber | `#EF9E69` | notification, loneliness → healing motif |
| slate | `#383E49` | glass and foreground depth |

**Display:** DejaVu Sans Bold with Vietnamese glyph coverage, 67–91px.
**Support:** 24–32px, controlled tracking. 
**Mobile-safe:** headers ≥195px below frame top, subtitle ~1567px and progress y≈1633px; avoid important CTAs behind Shorts buttons / bottom chrome.

**Frame 0 wireframe:** [top small chapter] [BIG: 17 TIN NHẮN] [left: lonely An / right: glowing message screen] [short caption] [progress].
**Conversation shot:** [same actor anchor] [phone screen insert at right] [short quote] [restrained amber].
**Payoff:** [An at candle] [screen light becomes flame] [BẠN CŨNG XỨNG ĐÁNG ĐƯỢC THƯƠNG].

**Generic default check:** reject rainbow gradients, stock photography, fake app UI, oversized emoji, word-by-word glitch captions, random particles and continuous whip cuts. Use one unique recurring motif: phone light → candle.
**Revision from prior shorts:** persistent character anchor and global camera, cross-dissolve scenic elements beneath actor, no full-scene reset at cuts; independent scene art always says something new.
