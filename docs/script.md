# Kịch bản thoại — 43 giây

## Bản đọc

Ngày đầu vào team. Repo hai trăm nghìn dòng code. Sếp bảo: “Em xem nhanh kiến trúc nhé.” Nhanh… kiểu ba ngày hả anh?

Mở file đầu tiên. File gọi file. File lại gọi thêm bảy file. Mười phút sau, bạn chính thức chuyển nghề… khảo cổ codebase.

Understand Anything quét project, gom file, function, class và dependency thành knowledge graph có thể bấm, tìm và hỏi.

Muốn biết phần nào xử lý đăng nhập? Gõ câu hỏi. Nó dẫn tới node liên quan, rồi guided tour chỉ luôn thứ tự nên học.

Trước khi commit, xem thay đổi này ảnh hưởng chỗ nào. Đỡ cảnh sửa nút đăng nhập mà giỏ hàng cũng… giận dỗi.

Cài plugin, chạy `understand`, rồi nhìn codebase từ búi mì thành bản đồ. Link ở phần mô tả — đỡ đào code bằng thìa nha!

## Nhịp hài

- Thiết bị chính: phóng đại tình huống quen thuộc.
- Callback duy nhất: “khảo cổ” → “đào code bằng thìa”.
- Punchline xuất hiện trước giây 6 và lần hai quanh giây 33.
- Lưu ý trung thực dạng chữ nhỏ: lần quét đầu của repo lớn có thể tốn nhiều token; các lần sau incremental.
