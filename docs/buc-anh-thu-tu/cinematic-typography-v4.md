## Title / subtitle design tokens

| Token | Value | Intent |
|---|---|---|
| Display | Inter Display Black | Cinematic poster headings |
| Narration caption | Inter Bold | Vietnamese diacritics; 1–2 balanced lines, no orphan word |
| Base | `#F7F0E7` | Warm off-white |
| Horror / payoff | `#FF394C` | Red for threat, climax, reversal |
| Discovery | `#F5C66B` | Warm amber emphasis |
| Secondary | `#B3B9C1` | Chapter name, run time and ornaments |
| Background | `#06080C` | Near-black noir |
| Frame | 720×1280 | Native vertical 9:16 |

- Permanent upper micro-branding, 2-line poster title (white first line, color second), scene index and cinematic progression line.
- Two narration caption beats per shot with gentle enter/exit animation and balanced Vietnamese line wrapping, set against a translucent darkness gradient in the lower safe area.
- Clear 50px+ horizontal margin; caption begins around y=807 and stays clear of scene art and end-screen UI safe zones. No hardcoded fake timers.
- Last scene presents the complete payoff, not an abrupt unexplained cliffhanger.
- Animation: 0.5s crossfades, subtle dolly/camera pan; avoid violent shake or random transition overuse.
