# GIÂY THỨ 61 — 16:9 Long-form Horror Design

Date: 2026-10-30. Status: design implemented as **local V1 motion-comic REVIEW**, not approved FINAL.

## Intent
Create an original psychological/screenlife horror movie in Vietnamese lasting 90–180s, specifically **135s** in 16:9. The central paranormal mechanism is a camera file of exactly 60s whose editing timeline has an impossible 61st second recording the protagonist's immediate future.

## Audience and goals
- Hook with impossible video evidence immediately, escalating every 5–7s.
- Explain its rules through monitor evidence and protagonist actions, not a disembodied monster.
- Make the deletion event the causal trigger for the protagonist becoming trapped in a screen; cliffhanger: camera 02 opens for the next person.
- Provide separate intro (0–3s) and contextual follow/like outro (130–135s). Use original genuine Vbee Anh Khôi narration, native proper Vietnamese captions and sound design.
- Film is 16:9 despite previous Ray Shorts 9:16 defaults: the owner explicitly requested horizontal long-form.

## Explored approaches
1. **Photorealistic AI live-action clips**: strongest acting potential, but requires many consistent independent generations and more QA/compute; unavailable within this build.
2. **Screenlife 2D/2.5D procedural composition**: controllable action/timeline proof, original assets and fast iteration; lower character realism. **Chosen as V1 REVIEW**; not a hidden substitute for live action.
3. **Storyboard image slideshow**: quick but no true action evidence; rejected.

## Design system
Ink black, petroleum teal, dim warm desk lamp, restrained warning red around timestamp 61 and delete confirmation. An editor room plus nested CCTV/source viewer. Not a horror gore film.
Native font Noto Sans with proper Vietnamese glyphs; intro/title distinct from exact narration captions. No baked review timecodes or grids.

## Narrative rules
Camera file is 60s, playhead at phantom second 61 shows the near future. Attempts to avert events become part of the prediction. File deletion removes the actual editor from the room and traps him inside digital footage. The new CAMERA 02 file indicates a new impending victim.

## Hard constraints
16:9; 135s; 22 shots; 22 actual SHA-verified Vbee Batch MP3s; separate opening/closing CTA; no YouTube publishing without approval; no copyrighted music; no GitHub Releases per latest user override. All archival video files on numbered private Google Drive.

## Acceptance
MP4 H.264/AAC with 135s, 1280x720 at 24fps; 3,240 frames; exact voice match, no clip cutoff; frame-by-frame story evidence; full decoder PASS. Review—not FINAL—until original independent high-fidelity scene assets, editorial acting proof and Remotion canonical verify/visual/audit gates are actually passed.
