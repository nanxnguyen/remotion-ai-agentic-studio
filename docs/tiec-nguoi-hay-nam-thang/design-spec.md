# Design spec — provisional, requires independent Gate D

Pure black background; white vector stick characters; orange only for active memory or turning point. Character always circular head radius 44 on 1080 canvas, 9px rounded strokes, consistent 1:4.2 head/body relationship. One focal subject per frame.

- s1: protagonist points at almost-empty current-day calendar (question).
- s2–s3: narrator and one friend converse, NOT partner; friend pauses.
- s4: abstract memory frames behind friend; partner only implied in memory and never shown in current dialogue.
- s5: blank frame symbolises present; friend no longer talking.
- s6: one friend holds calendar pages, not a person.
- s7: calendar moves aside while orange highlight stays on elapsed days: years had meaning.
- s8: protagonist at an unmarked fork, one path with silhouette, one with calendar; *no choice is shown*.

Caption headline top middle safe area; body typography Be Vietnam Pro or bundled Vietnamese-capable sans, 68px+; orange accent #F28C52; secondary #BDBDBD. All motion deterministic via useCurrentFrame, interpolate and spring. No timers, DOM time or randomness.
