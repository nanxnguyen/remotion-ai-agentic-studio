# KHÔNG AI VỖ TAY CHO NGÀY ĐẦU TIÊN — V5 / GATE 1

**Phim thử nghiệm 15 giây (chưa phải bản final 140 giây).**

- Chạy `python -m unittest discover -s src -p 'test_v5.py' -v`.
- Chạy `python src/render_gate1.py` để dựng MP4 đầy đủ; yêu cầu Python 3, Pillow, NumPy, FFmpeg (H.264/AAC encoder).
- Chạy `python src/render_gate1.py preview` để dựng 16 frame preview (chưa phải kết quả QA final).
- Xem `QA-V5-GATE1.md` để đọc các giới hạn nghệ thuật thực tế và gate chưa duyệt.

Thiết kế vector và âm thanh tổng hợp nguyên bản; không sao chép tác phẩm tham chiếu. Source V5 hiện độc lập Remotion; phần port sang repo là bước tiếp theo sau khi gate artistic được duyệt.
