# Closing CTA — mandatory 3–5 seconds

Use this rule whenever Ray Phim Kể Chuyện scripts, storyboards, renders or revises a video. **Reserve 3–5 seconds INSIDE the approved total running time for a story-specific like + follow/subscribe line.** Do not automatically reuse a fixed CTA from a previous movie.

Read `skills/ray-phim-ke-chuyen/references/story-specific-cta-outro-v1.md` before script and timeline lock. Keep the actual payoff before CTA. Pick a line that suits genre, voice, emotional stakes, destination platform and final visual. It should invite BOTH a like and a follow/subscribe, without claiming guaranteed views.

Record an authentic, measured Vbee utterance for the final approved wording, verify native Vietnamese subtitles and SFX match it, and inspect actual final MP4 ending. Storyboard review can display the CTA as the last card, but no storyboard header/timecode may appear in the film. **Respect explicit user overrides** (e.g. no CTA, silent ending or altered duration).
