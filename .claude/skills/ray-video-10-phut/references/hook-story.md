# Story and hook design — ethical, clear, retention-oriented

## Before writing

Define: **Who is watching? What is their unresolved question? Which one insight can they retell? What proof can be shown?** Never promise more in the hook than the payoff can substantiate.

Draft **three genuinely different hooks**; select one:

1. **Specific contrast**: “Bạn nghĩ [A]; bằng chứng từ [source] lại cho thấy [B].” — only if supported.
2. **Micro-mystery**: “Một chi tiết trong [object] thay đổi toàn bộ cách nhìn về [question].” — reveal within video, not clickbait.
3. **Human stakes**: “Nếu bạn đang [pain], đừng bỏ qua [concrete observable consequence].” — avoid alarmist false urgency.

Internal hook review (not pipeline Gate A): immediate comprehensibility without audio, specific subject in frame 0, emotional/utility promise, deliverable proof, visualizability. Reject generic “Bạn có biết…”, empty suspense, unsupported superlatives and disguised ads.

## Beat map for a 30–45 second vertical video

| Time | Audience job | Production directive |
|---|---|---|
| 0–3s | Understand *why this matters* | Strong image + caption, no black opening, active visual |
| 3–10s | Establish context & promise | One image/idea at a time, clear premise |
| 10–20s | Encounter complication/re-hook | Visible contrast, new question, reveal or stake; re-hook about 15–20s |
| 20–32s | Receive substantiated answer | Show real evidence/demonstration, not just talking text |
| 32–45s | Remember one line | Payoff, controlled breath, ending hold; CTA only if relevant |

These windows are **creative guidelines**, not overrides for user duration or measured audio. Video may be 15–60s on explicit brief, but 10-minute SLO eligibility tightens accordingly.

## Profile choice

- **Story**: tension → specific sensory detail → reversal → emotional landing. Human details over abstractions.
- **Knowledge**: misconception/question → concrete mechanism → demonstrable conclusion. Sources and definitions.
- **Product**: problem → genuine demonstration → differentiator/proof → clear user next step. No fabricated benefits.
- **News**: confirmed event/time → stakes → sourced fact → context/uncertainty. Date and attribution mandatory.

## Script/voice fit

- Write `script.md` shot-by-shot including exact spoken line and onscreen content. One primary idea per shot.
- Initial Vietnamese timing may use ~3.7–4.2 **space-separated syllables/s** per original source; then replace estimates with measured TTS durations, accounting for silence and holds.
- Script contains directions for delivery, stress and breath in **non-spoken fields**; `voice.json` is canonical speech text. Captions must exactly match the intended canonical source.
- Explicitly label up to three highlight beats, each with voice emphasis + visual emphasis + (if appropriate) restrained sound cue.
- Place a final silence/hold after the last important line; do not cram payoff and CTA into the same breath.
- A content reviewer checks claims, source and understanding; a separate integration reviewer judges script + voice + pictures together.

## Quick test questions

- Would an unfamiliar viewer know the topic with sound off by second 2?
- Is the promised answer demonstrably delivered, not deferred?
- Is there an obvious reason the image must move rather than remain a generic text card?
- Can the viewer retell one sentence a minute later?
- Are all concrete claims sourced and all visuals correctly labelled as proof, analogy or illustrative only?
