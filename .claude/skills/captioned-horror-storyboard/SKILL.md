# Captioned horror storyboard

For the user’s reference look of Căn Phòng 404 and Bức Ảnh Thứ Tư, every review panel must contain legible story-focused Vietnamese caption and white/yellow/red emphasized key phrases, in a cinematic grid. 16 diverse panels by default, optionally with header. Use a separate typography renderer to guarantee correct diacritics. **Do not put review captions, board borders or timecodes into final MP4.** Use clean independent source assets and native video subtitles.
