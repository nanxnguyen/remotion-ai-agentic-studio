# Ray Tạo Video Tâm Lý Học · v1.0.0

Skills-only private ChatGPT plugin for repeatable **original Vietnamese psychology stick-figure Shorts**. This package includes durable production instructions, scientific integrity gates, verified voice candidates, Remotion motion/caption quality standards, YouTube rights/monetization safeguards, Google Drive SOP and a local FFmpeg QA checker.

It does not bundle or claim access to Vbee credentials, Google Drive permissions, GitHub Actions or YouTube publishing. Actual videos require available authorized runtime/actions and manual review. Supports V1 REVIEW → V2 → FINAL workflows while preserving prior files.

Reference original case: Ray #27 people-pleasing psychology Shorts (see `references/production-case-study-27.md`).
