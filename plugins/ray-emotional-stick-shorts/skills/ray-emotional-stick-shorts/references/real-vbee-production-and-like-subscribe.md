# Ray Shorts — real Vbee, cinematic production and Like + Subscribe CTA

Version: 1.1 — 2026-10-27. Owner-required process based on video #24 “Bố ơi, hôm nay con không đợi nữa”. Applies to future original Vietnamese emotional stick-figure Shorts. This is a **required production checklist**, not proof that one particular film has passed all gates.

## Workflow: real assets, real media, verified delivery

1. **Story & script:** Write an original 40–45s story, default 45s, using 10 intentional beats: 0–3s story-specific curiosity intro; strong hook by 6s; observable character/prop actions and re-hook to 25s; climax and emotional twist 25–39s; meaningful payoff 39–41/42s; **1–4s final CTA to BOTH thả tim and đăng ký/theo dõi kênh**. Avoid fake facts and manipulative guarantees. CTA may be blended into last sentence if synthesis needs breathing room. The key emotional reveal must come before the CTA.
2. **Storyboard and shotlist:** 10 timecoded narrative scenes with beat ID, real narration, frame composition, character expressions and prop continuity, lens/framing, movement and lighting, SFX/piano cues, max-two-line captions. Strong first frame and purposeful shot variation; no decorative filler. If using image-generated concepts, they are **references**, not proof of animated/rendered footage.
3. **Genuine Vbee HN Thanh Long:** Generate actual authorized Vbee narration using protected credentials (e.g. GitHub Actions `VBEE_APP_ID`/`VBEE_ACCESS_TOKEN`); default voice code `hn_male_thanhlong_talk_48k-fhg` when supported. Do not expose secrets/log bearer links, claim successful TTS before the audio exists, or silently substitute a different voice. Record request status, sample rate and **actual measured duration**. A 48k voice code does not guarantee the downloaded MP3's native sample rate; inspect its real stream. For a CTA change, regenerate the affected line with **the same genuine Vbee voice** and retime, or transparently label a visual-only CTA if voice synthesis cannot be done. Never call a silent/stand-in CTA "real Vbee".
4. **Avoid known runner failure:** GitHub Actions may have Vbee secret access but lack `ffprobe`; install FFmpeg with an explicit step or validate MP3 ID3/MPEG bytes+size+SHA256 using Python before uploading. `actions/upload-artifact` must still be reached and the non-expired artifact ID checked; a generated file in a failed job is **not delivered**. Download/verify the real MP3 before editing film.
5. **Animated film production:** Prefer proper Remotion scene components/typed timeline/source, original piano and licensed assets; if using Pillow/FFmpeg, label the implementation accurately and do not claim Remotion-native. Every narrated essential action should be shown visually. Verify hands/legs attached, contact with props, facial expression, lip/noise and framing; use actual observed frames and scene transitions.
6. **Edit voice, music, captions and CTA:** Align scenes to **real Vbee dialogue**, preserve storytelling pauses; mix piano quieter than voice with ducking and no clipping. Build large high-contrast Vietnamese captions, max two lines, white/cream + restrained amber, no opaque black boxes and no safe-zone clashes. Close with a **story-relevant spoken CTA explicitly saying “thả tim” AND “đăng ký kênh”** plus a restrained animated heart + Subscribe control for 1–4 s. Do not repeat the CTA in oversized banners or overlay it over the tearful climax. Example: “Nếu câu chuyện chạm đến bạn, hãy thả tim và đăng ký kênh nhé.” Time phrase by measured speech; if longer than 4 s, trim wording, don't accelerate unnaturally.
7. **Independent media QA:** Probe the exact new MP4 via ffprobe: 9:16 1080×1920, 30fps preferred (or explicit 60fps), H.264, yuv420p, AAC stereo **48 kHz**, 40–45s target unless user overrides. Decode the **entire** MP4 and sample opening, 10 scenes, twist, CTA and last frame; review 360×640 phone preview. Listen to both voice and piano and check timestamps. A passing ffprobe alone does **not** pass cinematic QA, accurate word-level subtitle sync or native Remotion QA. Do not label FINAL until human/independent quality gates and user approval.
8. **Google Drive single-folder SOP:** **BEFORE EACH SAVE** list root `Videos-shorts` ID `1rtJF9zDWuFZ8_6IixdMew3WCZj8415-D` through all pages, match stable topic by canonical ID/slug/title, reuse folder for new V1.1/V2 and all assets. Only truly new topic gets `max(numbered direct children)+1`; never use guessed numbers. Keep old files/links, version filenames, compare name/size/hash. Upload MP4, authentic Vbee MP3, source package, quality report, title/description, thumbnail/manifest when available, then verify each returned ID, URL, MIME, parent folder and bytes. No overwrite/delete without explicit consent. **Drive hosts deliverable MP4; GitHub hosts source/QA**, follow newer repository AGENTS.md, not obsolete GitHub Release instructions.
9. **Handoff:** Give a verified MP4 and folder link, review/FINAL label, measured duration, voice provenance, what improved, outstanding quality issues. If any step fails, deliver only actual completed artifacts and exact remaining blockers. Never claim viral performance without audience data.

## Required QA before announcing CTA success

- Audio recording contains both spoken requests **"thả tim"** and **"đăng ký kênh"**, when narrated CTA is requested; inspect/listen to final mix, not merely transcript.
- Video visibly includes recognizable heart and subscribe prompts during its 1–4s closing interval, with mobile-safe layout; fades without abrupt ending.
- The same original story and emotional payoff are preserved, old V1 stays available, and new revision has its own Drive file and asset manifest.
