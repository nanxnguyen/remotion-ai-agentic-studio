# SMOOTH_CINEMATIC_VIDEO_V1 — default motion production standard (2026-10-24)

**Latest user priority supersedes mandatory independent lifelike actor animation:** natural *video* motion without stalls/jitter is REQUIRED; lifelike full-body acting of characters is OPTIONAL. Remotion/FFmpeg cinematic 2D/2.5D motion-comic is an acceptable FINAL form after full source/video/audio QA. Do not call 2D scene transforms actual human acting.

## Recommended smooth cinematic tools

- Independent story-specific full-vertical clean photos/clips, character bible, varied wide/close/detail angles (do not animate the review contact sheet as a full video shot).
- Fractional/subpixel camera transforms, long smooth easing, purposeful depth/parallax, controlled foreground drift, reflections, focus/lighting/particles, 0.25–0.45s cinematic crossfades and motivated hard cuts; clean Vietnamese kinetic captions.
- No unintentional static freeze or stop-and-go motion, no frame skipping/duplicates, integer-crop rounding jumps, massive repeated Ken Burns zoom, unwanted shake, flicker/strobe or abrupt mismatched speed at scene boundaries. Suspenseful short intentional holds are fine if timed with the plot.
- No mandatory video model credits. Use live acting/video generation optionally, never halt a final just because the animation is built from still scene photos; nevertheless a truly static slideshow with no narrative movement fails this motion standard.
- Match real measured Vbee Batch to visual storytelling and cinematic subtitles and sound cues. The image should illustrate actions through framed evidence, controlled cut and scene progression. Don't misrepresent absent physical movement.
- Keep 9:16, <=60s; 30fps accepted, 60fps when video playback is actually smooth; FPS upscaling alone proves nothing.
- **QA actual MP4** in motion: inspect first 6 seconds, 18–24s, 30–48s, 48–60s, all boundaries and adjacent samples; listen to audio. Check stutter/jumps, flicker, face identity, subtitle/timecode contamination, safe area, narration/SFX, and ffprobe format. Pass new `motion_smoothness` final QA checklist (replaces `actor_emotion`). Intentional impact cuts do not fail smoothness.
- Existing HOOK 0–6s, BODY 6–30s, CLIMAX 30–48s, PAYOFF 48–60s; final destination unchanged: numbered existing movie folder in Google Drive with MP4, original thumbnail and Vietnamese YouTube copy plus draft GitHub Release MP4; report both verified URLs.
- **FINAL approval no longer depends on physically moving humans**; it does depend on excellent temporal smoothness and storytelling/voice/caption/export tests. State technique accurately (cinematic 2D/2.5D versus actual actor performance).

If any older user-specific requirement in this plugin says `FULL ACTOR MOTION REQUIRED` or `motion-video credits blocked`, this newer policy overrides it, while honest technical characterization remains mandatory.
