# Horror package — title, thumbnail, description

Read `../make-horror-video/references/packaging.md` first (formulas, thumbnail rules, description template, Shorts funnel, policy), and for **Option C (Dạ Hành Dị Tạp folklore style)** also read `../make-horror-video-ditap/references/ditap-playbook.md` (Section 3: Minimal Title Formula, Split-Color Thumbnail Formula, and Pinned Community Comment Template). The thumbnail engine is the studio kit (`../make-horror-video/kit/`, installed as `truyenma-studio/`; see `../make-horror-video/references/install.md`) and `horror-engine-api.md` → `H.thumbText` (`/engine/horror.js`) or `D.ditapThumbText` + `D.ditapBigFace` (`/engine/ditap.js`).

## Workflow
1. **Get the story.** Read the project's `story/script.md` / `story/bible.md` if a project exists; otherwise ask for the script or a summary. Identify: the entity's signature trait, the hook image, the twist (never reveal it in packaging).
2. **Titles.** Write 5 options in the video's language with the formulas in `packaging.md` (or for Option C Dạ Hành Dị Tạp: minimal `[Từ khóa dân gian / cấm kỵ] - [Chi tiết số đếm / vật định mệnh]` titles such as *Thần Trùng - Chiếc Khăn Tang Thứ Ba Mươi Hai*, with zero `| Truyện Ma...` suffix clutter); score each (curiosity gap, specificity, honesty, length ≤ 60 chars); recommend the top one and an A/B alternative.
3. **Thumbnails.** Design 3 concepts that complete (not repeat) the recommended title: entity close-up, human reaction with the threat behind, or the key object glowing. In the project write `scenes/shots/thumb.js` registering `thumb`, `thumb2`, `thumb3` (use `H.thumbText` with 2–4 words, `H.thumbArrow`/`thumbCircle` if useful, or for Option C use `D.ditapThumbText` with massive split-color white `#ffffff` + crimson `#ff2a2a` / gold `#ffd23f` lines alongside `D.ditapBigFace` and a `faceless: true` figure in `D.ditapAltar`). If no project exists, create one with `python tools/new_project.py --name <slug>-thumb --duration 3 --aspect 16:9 --lang <code> --style amhon` and write the thumb module there. Run `python tools/make_thumb.py --project projects/<slug> --variants 3`, open each PNG, fix readability at small size (view it scaled to 320 px wide), then send the PNG/JPG files.
4. **Description pack.** Write `out/publish.txt`: the chosen title + alternative, description (tease + chapters from shots.json beats/chapters + fiction note + hashtags), tags, pinned-comment question (including the folklore taboo community template from `ditap-playbook.md` when applicable), and a Shorts plan (2–4 cut-downs with start/end times and their own titles).
5. **YouTube Upload Sync.** Whenever the user requests pushing a finished video to YouTube, bundle and upload **all four packaging elements together** in `config/films/<slug>.json` + workflow inputs: **Title (`title`)**, **Description (`description`)**, **Tags (`tags`)**, and **Thumbnail (`thumbnail_drive_id`)** alongside `video_drive_id` (always `execute=false` dry-run first, then `Private` upload).
6. **Check policy.** No gore or fake UI in thumbnails, fiction labelled, not made for kids, disclosure only if a realistic real person/event is depicted.
